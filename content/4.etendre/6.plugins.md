Un plugin regroupe des commandes, des subagents, des skills, des hooks et/ou des serveurs MCP dans un seul paquet installable — un moyen de récupérer d'un coup une extension prête à l'emploi, ou de partager la tienne avec ton équipe de façon versionnée.

## Quand l'utiliser

Quand tu veux une intégration déjà prête (GitHub, Slack, Sentry, une revue de sécurité automatique...) sans tout configurer à la main, ou quand tu veux partager tes propres commandes, skills ou hooks avec ton équipe ou la communauté, plutôt que de les recopier manuellement dans chaque projet.

## Exemple minimal

Claude Code ajoute automatiquement la marketplace officielle d'Anthropic (`claude-plugins-official`) dès ton premier lancement interactif. Pour parcourir ce qu'elle propose et installer un plugin :

```bash [Terminal]
/plugin
```

Ou directement en ligne de commande, pour installer l'intégration GitHub :

```bash [Terminal]
/plugin install github@claude-plugins-official
```

## Exemple réaliste

Installer un plugin depuis une marketplace de démonstration, pour voir tout le cycle : ajouter la marketplace, parcourir son catalogue, installer, puis utiliser une commande fournie par le plugin.

::steps{level="3"}
### Ajouter la marketplace

```text [Dans la session Claude Code]
/plugin marketplace add anthropics/claude-code
```

### Parcourir les plugins disponibles

```text [Dans la session Claude Code]
/plugin
```

Va dans l'onglet **Discover** pour voir les plugins de la marketplace que tu viens d'ajouter. Le panneau de détail d'un plugin montre son coût en contexte, sa dernière mise à jour, et la liste de ce qu'il va installer (commandes, skills, agents, hooks, serveurs MCP...).

### Installer un plugin

```bash [Terminal]
/plugin install commit-commands@claude-code-plugins
```

Choisis un scope d'installation : personnel (tous tes projets), projet (partagé avec l'équipe via `.claude/settings.json`), ou local (juste toi, sur ce projet).

### Utiliser le plugin

Les commandes d'un plugin sont préfixées par son nom :

```text [Dans la session Claude Code]
/commit-commands:commit
```

Cette commande récupère les changements en cours, génère un message de commit, et crée le commit.
::

## Pièges fréquents

::warning
**Un plugin peut exécuter du code arbitraire sur ta machine, avec tes privilèges.** Anthropic ne contrôle pas ce que contiennent les serveurs MCP ou les scripts fournis par un plugin tiers et ne peut pas garantir qu'ils font ce qu'ils prétendent faire. N'installe que des plugins et des marketplaces auxquels tu fais confiance.
::

::note
**Les commandes d'un plugin sont toujours préfixées par son nom.** Un plugin nommé `commit-commands` expose `/commit-commands:commit`, jamais `/commit` tout court — c'est volontaire, pour éviter qu'un plugin n'entre en collision avec une commande d'un autre plugin ou avec une commande que tu as toi-même créée.
::

::caution
**Une installation peut rester en attente le temps d'un rechargement.** Si le résumé d'installation affiche `Run /reload-plugins to activate.`, le plugin n'est pas encore actif dans la session en cours — Claude Code lance ce rechargement pour toi, mais si le message parle d'invalider le cache de prompt, il faut relancer `/reload-plugins --force` toi-même pour l'activer.
::

::caution
**Retirer une marketplace désinstalle tous les plugins qui en viennent.** `/plugin marketplace remove` ne fait pas que retirer la marketplace de ta liste : elle désinstalle aussi tout ce que tu avais installé depuis elle.
::
