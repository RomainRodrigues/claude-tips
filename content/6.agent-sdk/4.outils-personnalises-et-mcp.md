Un **outil personnalisé** est une fonction que tu écris toi-même et que Claude peut appeler pendant une session ; le **MCP** (Model Context Protocol) est le standard ouvert qui permet de connecter ton agent à des outils externes (bases de données, API comme Slack ou GitHub) sans les réimplémenter.

::note
Ces deux mécanismes existent dans le **Agent SDK**, le kit pour développeurs qui construisent leur propre agent. Si tu veux juste ajouter un serveur MCP à ton Claude Code du terminal (par exemple pour qu'il accède à ta base de données pendant que tu codes), c'est la page [MCP](/etendre/mcp) de la section « Étendre Claude Code » qu'il te faut, pas celle-ci.
::

## Quand l'utiliser

Écris un **outil personnalisé** quand ton agent doit accéder à une logique ou une donnée propre à ton application (appeler ta propre API, une fonction métier interne). Connecte un **serveur MCP externe** quand un serveur existe déjà pour le service que tu veux (filesystem, GitHub, Slack, une base Postgres...) — inutile de réinventer ce qui est déjà standardisé.

## Exemple minimal

Un outil se définit en quatre parties : nom, description, schéma d'entrée, fonction de traitement (« handler »). Tu l'enveloppes ensuite dans un serveur MCP qui tourne **dans le même processus** que ton application (`create_sdk_mcp_server` / `createSdkMcpServer`), puis tu le passes à `query()` via `mcpServers`.

::code-group
```python [weather.py]
from typing import Any
import httpx
from claude_agent_sdk import tool, create_sdk_mcp_server, query, ClaudeAgentOptions, ResultMessage
import asyncio

@tool(
    "get_temperature",
    "Récupère la température actuelle à un endroit donné",
    {"latitude": float, "longitude": float},
)
async def get_temperature(args: dict[str, Any]) -> dict[str, Any]:
    async with httpx.AsyncClient() as client:
        response = await client.get(
            "https://api.open-meteo.com/v1/forecast",
            params={
                "latitude": args["latitude"],
                "longitude": args["longitude"],
                "current": "temperature_2m",
                "temperature_unit": "fahrenheit",
            },
        )
        data = response.json()
    return {"content": [{"type": "text", "text": f"Température : {data['current']['temperature_2m']}°F"}]}

weather_server = create_sdk_mcp_server(name="weather", version="1.0.0", tools=[get_temperature])

async def main():
    options = ClaudeAgentOptions(
        mcp_servers={"weather": weather_server},
        allowed_tools=["mcp__weather__get_temperature"],
    )
    async for message in query(prompt="Quelle température fait-il à San Francisco ?", options=options):
        if isinstance(message, ResultMessage) and message.subtype == "success":
            print(message.result)

asyncio.run(main())
```

```typescript [weather.ts]
import { tool, createSdkMcpServer, query } from "@anthropic-ai/claude-agent-sdk";
import { z } from "zod";

const getTemperature = tool(
  "get_temperature",
  "Récupère la température actuelle à un endroit donné",
  { latitude: z.number(), longitude: z.number() },
  async (args) => {
    const response = await fetch(
      `https://api.open-meteo.com/v1/forecast?latitude=${args.latitude}&longitude=${args.longitude}&current=temperature_2m&temperature_unit=fahrenheit`
    );
    const data: any = await response.json();
    return { content: [{ type: "text", text: `Température : ${data.current.temperature_2m}°F` }] };
  }
);

const weatherServer = createSdkMcpServer({ name: "weather", version: "1.0.0", tools: [getTemperature] });

for await (const message of query({
  prompt: "Quelle température fait-il à San Francisco ?",
  options: {
    mcpServers: { weather: weatherServer },
    allowedTools: ["mcp__weather__get_temperature"]
  }
})) {
  if (message.type === "result" && message.subtype === "success") {
    console.log(message.result);
  }
}
```
::

Le nom complet de l'outil pour Claude devient `mcp__{nom-du-serveur}__{nom-de-l'outil}` — c'est ce nom qu'il faut lister dans `allowedTools` pour éviter une demande de permission à chaque appel.

## Exemple réaliste

Pour se connecter à un serveur MCP **externe** plutôt que d'en écrire un, il suffit de le déclarer dans `mcpServers` avec son type de transport : `command`/`args` pour un processus local (stdio), ou `type: "http"` / `"sse"` pour un serveur distant.

::code-group
```python [github.py]
import asyncio, os
from claude_agent_sdk import query, ClaudeAgentOptions, ResultMessage, SystemMessage

async def main():
    options = ClaudeAgentOptions(
        mcp_servers={
            "github": {
                "type": "http",
                "url": "https://api.githubcopilot.com/mcp/",
                "headers": {"Authorization": f"Bearer {os.environ['GITHUB_TOKEN']}"},
            }
        },
        allowed_tools=["mcp__github__list_issues"],
    )

    async for message in query(
        prompt="Liste les 3 issues les plus récentes de anthropics/claude-code",
        options=options,
    ):
        # Vérifier que le serveur MCP s'est bien connecté
        if isinstance(message, SystemMessage) and message.subtype == "init":
            print("Serveurs MCP :", message.data.get("mcp_servers"))
        if isinstance(message, ResultMessage) and message.subtype == "success":
            print(message.result)

asyncio.run(main())
```

```typescript [github.ts]
import { query } from "@anthropic-ai/claude-agent-sdk";

for await (const message of query({
  prompt: "Liste les 3 issues les plus récentes de anthropics/claude-code",
  options: {
    mcpServers: {
      github: {
        type: "http",
        url: "https://api.githubcopilot.com/mcp/",
        headers: { Authorization: `Bearer ${process.env.GITHUB_TOKEN}` }
      }
    },
    allowedTools: ["mcp__github__list_issues"]
  }
})) {
  // Vérifier que le serveur MCP s'est bien connecté
  if (message.type === "system" && message.subtype === "init") {
    console.log("Serveurs MCP :", message.mcp_servers);
  }
  if (message.type === "result" && message.subtype === "success") {
    console.log(message.result);
  }
}
```
::

Un exemple avec un serveur local (`stdio`), ici un serveur filesystem qui tourne en sous-processus — remplace `/Users/me/projects` par un dossier de ta machine :

```typescript [filesystem.ts]
import { query } from "@anthropic-ai/claude-agent-sdk";

for await (const message of query({

    mcpServers: {
      filesystem: {
        command: "npx",
        args: ["-y", "@modelcontextprotocol/server-filesystem", "/Users/me/projects"]
      }
    },
    allowedTools: ["mcp__filesystem__*"]
  }

  if (message.type === "result" && message.subtype === "success") {
    console.log(message.result);
  }
}
```

## Pièges fréquents

::warning
**Un outil MCP sans `allowedTools` reste invisible pour l'exécution.** Claude voit que l'outil existe mais ne peut pas l'appeler tant qu'il n'est pas autorisé, explicitement (`mcp__serveur__outil`) ou avec un joker (`mcp__serveur__*`). Ça vaut aussi bien pour un outil personnalisé que pour un serveur externe.
::

::caution
**`acceptEdits` n'auto-approuve pas les outils MCP.** Ce mode de permission ne couvre que les modifications de fichiers et les commandes filesystem — pas les appels MCP. Pour auto-approuver un outil MCP, utilise `allowedTools` avec un joker plutôt que `bypassPermissions`, qui désactive beaucoup plus de garde-fous que nécessaire.
::

::note
**Une erreur dans un handler ne fait pas planter l'agent.** Le serveur MCP intégré intercepte les exceptions non gérées et les transforme en résultat d'erreur que Claude peut lire et sur lequel il peut réagir. Si tu veux composer toi-même le message que Claude reçoit (au lieu du message d'exception brut), retourne `isError: true` (`is_error: True` en Python) avec ton propre texte.
::

::warning
**Beaucoup de serveurs MCP consomment du contexte.** Chaque outil déclaré ajoute son schéma au contexte envoyé à chaque tour. La [recherche d'outils](https://code.claude.com/docs/en/agent-sdk/tool-search) (« tool search ») est activée par défaut et diffère le chargement des schémas MCP pour limiter ce coût — vérifie ce comportement si tu connectes plusieurs serveurs avec beaucoup d'outils chacun.
::
