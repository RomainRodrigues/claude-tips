Le Agent SDK existe sous forme de deux bibliothèques officielles, une par langage : `@anthropic-ai/claude-agent-sdk` pour TypeScript et `claude-agent-sdk` pour Python. Les deux exposent la même fonction `query()` et les mêmes concepts (options, messages, hooks, permissions) vus dans le reste de cette section — seule la syntaxe change.

::note
Comme pour tout le reste de cette section, on parle ici du **Agent SDK** (construire ton propre agent), pas de Claude Code lui-même. Cette page est volontairement courte : c'est un point de départ vers les deux références API complètes, pas un tour exhaustif de chaque fonction.
::

## Installer et lancer

::code-group
```bash [TypeScript]
npm install @anthropic-ai/claude-agent-sdk
```

```bash [Python (uv)]
uv add claude-agent-sdk
```

```bash [Python (pip)]
python3 -m venv .venv
source .venv/bin/activate
pip install claude-agent-sdk
```
::

::note
Les deux SDKs embarquent un binaire natif de Claude Code comme dépendance optionnelle — dans la majorité des cas, tu n'as **pas** besoin d'installer Claude Code séparément. Si ton gestionnaire de paquets saute les dépendances optionnelles (par exemple `npm ci --omit=optional`), le binaire ne sera pas présent : installe Claude Code séparément et pointe `pathToClaudeCodeExecutable` vers lui.
::

## Exemple minimal dans chaque langage

Le point d'entrée commun aux deux SDKs est `query()` : une fonction qui prend un `prompt` et des `options`, et renvoie un flux asynchrone de messages.

::code-group
```typescript [agent.ts]
import { query } from "@anthropic-ai/claude-agent-sdk";

for await (const message of query({
  prompt: "Quels fichiers y a-t-il ici ?",
  options: { allowedTools: ["Glob"] }
})) {
  if (message.type === "result" && message.subtype === "success") {
    console.log(message.result);
  }
}
```

```python [agent.py]
import asyncio
from claude_agent_sdk import query, ClaudeAgentOptions, ResultMessage

async def main():
    async for message in query(
        prompt="Quels fichiers y a-t-il ici ?",
        options=ClaudeAgentOptions(allowed_tools=["Glob"]),
    ):
        if isinstance(message, ResultMessage) and message.subtype == "success":
            print(message.result)

asyncio.run(main())
```
::

La différence principale entre les deux SDKs, au-delà de la syntaxe (camelCase en TypeScript, snake_case en Python) : le SDK Python propose en plus `ClaudeSDKClient`, une interface avec état qui garde la session ouverte entre plusieurs appels `query()` (voir [Sessions et streaming](/agent-sdk/sessions-et-streaming)) ; le SDK TypeScript obtient le même résultat avec l'option `continue: true`.
