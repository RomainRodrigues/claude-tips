Claude Code est un programme en ligne de commande (`claude`) qui s'installe une fois sur ta machine, puis se lance depuis n'importe quel dossier de projet pour te donner un assistant IA qui lit et modifie ton code directement dans le terminal.

## Quand l'utiliser

C'est la toute première étape, avant tout le reste du site : sans installation, aucune des autres fonctionnalités (modes, mémoire, extensions...) n'est accessible. Tu n'as besoin de refaire cette étape qu'une seule fois par machine.

::note
Il te faut un compte payant Claude (Pro, Max, Team ou Enterprise) ou un compte Claude Console avec des crédits API. Le plan gratuit de claude.ai ne donne **pas** accès à Claude Code.
::

## Exemple minimal

Sur macOS, Linux ou WSL, une seule commande installe Claude Code :

::code-group
```bash [macOS / Linux / WSL]
curl -fsSL https://claude.ai/install.sh | bash
```

```powershell [Windows PowerShell]
irm https://claude.ai/install.ps1 | iex
```
::

Puis, dans n'importe quel projet :

```bash [Terminal]
cd mon-projet
claude
```

La première fois, Claude Code te demande de te connecter via le navigateur — suis simplement les instructions affichées.

## Exemple réaliste

Voici le déroulé complet, de l'installation à ta première vraie question posée à Claude, sur macOS/Linux.

::steps{level="3"}
### Installer

```bash [Terminal]
curl -fsSL https://claude.ai/install.sh | bash
```

Les installations natives (ce script) se mettent à jour automatiquement en arrière-plan par la suite — tu n'as rien à faire pour rester à jour.

### Vérifier que ça a marché

```bash [Terminal]
claude --version
```

Tu dois voir un numéro de version suivi de `(Claude Code)`, par exemple `2.1.211 (Claude Code)`. Si tu obtiens une erreur `command not found`, va directement au piège n°1 ci-dessous.

### Se connecter et lancer une première session

```bash [Terminal]
cd mon-projet
claude
```

Au premier lancement, Claude Code ouvre ton navigateur pour te connecter. Une fois connecté, tes identifiants sont enregistrés : tu n'auras plus besoin de te reconnecter les fois suivantes (sauf si tu veux changer de compte avec `/login`).

### Poser ta première question

Une fois dans la session interactive, tape simplement une question en langage naturel, sans commande spéciale :

```text [Dans la session Claude Code]
qu'est-ce que fait ce projet ?
```

Claude Code lit les fichiers du dossier courant et te répond directement dans le terminal.
::

## Pièges fréquents

::warning
**`command not found: claude`** — Le dossier d'installation (`~/.local/bin`) n'est pas dans ton `PATH`. Ajoute-le à la config de ton shell puis rouvre ton terminal :

:::code-group
```bash [Zsh (macOS)]
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc
```

```bash [Bash (Linux)]
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.bashrc
```
:::
::

::warning
**Sur Windows, mauvaise commande = mauvais shell.** `irm ... | iex` fonctionne uniquement dans **PowerShell**, pas dans l'invite de commandes (CMD) — et inversement pour la commande avec `curl` et `&&`. Ton invite affiche `PS C:\>` en PowerShell, et juste `C:\>` en CMD : vérifie lequel tu utilises avant de copier la commande.
::

::caution
**Claude peut agir sans te demander à chaque fois.** Sur les plans Pro, Max et Team, le mode de permission par défaut d'une session interactive (« auto mode ») laisse Claude modifier des fichiers et lancer des commandes sans te demander confirmation à chaque action. Si tu préfères valider chaque étape, appuie sur `Shift+Tab` pendant la session pour changer de mode.
::

::note
**N'installe jamais avec `sudo`.** Si tu utilises la méthode npm (`npm install -g @anthropic-ai/claude-code`), ne fais jamais précéder la commande de `sudo` : ça peut créer des problèmes de permissions durables sur ta machine.
::
