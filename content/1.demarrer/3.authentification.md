L'authentification est l'étape qui relie Claude Code à ton compte Claude (ou à une clé API) pour qu'il puisse réellement appeler le modèle et faire le travail.

## Quand l'utiliser

Tu la fais une première fois à l'installation, mais tu y reviens dès que tu veux changer de compte, que ton accès a expiré, ou que tu configures Claude Code sur une nouvelle machine.

::note
Il te faut un compte Claude Pro, Max, Team ou Enterprise, ou un compte Claude Console avec des crédits API. Le plan gratuit de claude.ai ne donne pas accès à Claude Code.
::

## Exemple minimal

Dans une session déjà lancée, pour te reconnecter ou changer de compte :

```text [Dans la session Claude Code]
/login
```

Pour te déconnecter complètement :

```text [Dans la session Claude Code]
/logout
```

## Exemple réaliste

Au tout premier lancement, `claude` ouvre ton navigateur pour te connecter :

::steps{level="3"}
### Lancer la première session
```bash [Terminal]
claude
```
Claude Code ouvre ton navigateur sur la page de connexion.

### Se connecter dans le navigateur
Choisis ton type de compte (Pro/Max/Team/Enterprise, Claude Console, ou un fournisseur cloud comme Amazon Bedrock). Si le navigateur ne s'ouvre pas automatiquement, appuie sur `c` dans le terminal pour copier le lien de connexion.

### Confirmer
Une fois connecté, le terminal affiche `Login successful` : appuie sur `Entrée` pour continuer. Tes identifiants sont désormais enregistrés, tu n'auras plus à te reconnecter la prochaine fois.

### Vérifier à tout moment
```text [Dans la session Claude Code]
/status
```
Affiche le compte actif, la méthode de connexion utilisée, et si ton login est proche d'expirer.
::

Si tu préfères utiliser une clé API plutôt qu'un compte (par exemple en CI), définis la variable d'environnement avant de lancer `claude` :

```bash [Terminal]
export ANTHROPIC_API_KEY="ta-clé"
claude
```

## Pièges fréquents

::warning
**Une clé API oubliée dans ton shell prend le dessus sur ton abonnement.** Si `ANTHROPIC_API_KEY` est définie dans ton environnement alors que tu as un abonnement Pro/Max/Team, Claude Code utilisera la clé API (facturée séparément à l'usage) plutôt que ton abonnement. Vérifie avec `/status`, et fais `unset ANTHROPIC_API_KEY` si tu veux repasser sur ton abonnement.
::

::caution
**Ne mets jamais ta clé API en dur dans un fichier versionné.** Passe-la toujours par une variable d'environnement ou un gestionnaire de secrets, jamais dans un script committé sur Git.
::

::note
**Un login qui expire bientôt t'avertit à l'avance.** Si tu vois `Your login expires in 3 days · run /login to renew` au démarrage, ce n'est pas bloquant tout de suite : lance simplement `/login` pour renouveler avant l'expiration réelle.
::
