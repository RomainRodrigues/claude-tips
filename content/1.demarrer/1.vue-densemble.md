Claude Code est un assistant IA **agentique** qui tourne dans ton terminal : contrairement à un simple chatbot, il ne se contente pas de te répondre en texte, il lit tes fichiers, exécute des commandes et modifie ton code directement pour accomplir la tâche que tu lui donnes.

## Quand l'utiliser

Dès que tu veux déléguer une tâche de développement plutôt que de tout faire toi-même : corriger un bug, ajouter une fonctionnalité, écrire des tests, comprendre un bout de code inconnu, rédiger de la documentation, ou même juste explorer un projet que tu découvres. Si c'est une tâche que tu pourrais faire depuis la ligne de commande, Claude Code peut probablement t'aider.

## Exemple minimal

Dans un projet, pose une simple question en langage naturel, sans commande spéciale :

```text [Dans la session Claude Code]
qu'est-ce que fait ce projet ?
```

Claude Code lit les fichiers pertinents et te répond directement.

## Exemple réaliste

Demande quelque chose de plus concret, comme corriger des tests qui échouent :

```text [Dans la session Claude Code]
les tests échouent, peux-tu regarder pourquoi et corriger ?
```

Claude Code enchaîne alors ce qu'on appelle la **boucle agentique** — il répète ces étapes jusqu'à ce que la tâche soit faite :

::steps{level="3"}
### Rassembler le contexte
Il lance la suite de tests pour voir ce qui échoue, puis lit le message d'erreur.

### Chercher et comprendre
Il cherche les fichiers concernés et les lit pour comprendre le code en cause.

### Agir
Il modifie le code pour corriger le problème.

### Vérifier
Il relance les tests pour confirmer que ça passe maintenant — et recommence si ce n'est pas encore bon.
::

Tu peux interrompre Claude à tout moment (`Esc`) pour le rediriger si tu vois qu'il part dans la mauvaise direction.

## Pièges fréquents

::note
**Claude Code agit, il ne fait pas que répondre.** Ce n'est pas un simple outil d'autocomplétion : il peut vraiment lancer des commandes et modifier des fichiers sur ta machine. C'est justement pour ça qu'il existe des [modes de permission](/usage-quotidien/modes-de-permission) qui contrôlent ce qu'il peut faire sans te demander.
::

::warning
**Chaque session démarre avec une mémoire vide.** Claude Code ne se souvient pas des conversations précédentes par défaut : seul le fichier [`CLAUDE.md`](/memoire-configuration/claude-md-et-memoire) et la mémoire automatique persistent d'une session à l'autre.
::
