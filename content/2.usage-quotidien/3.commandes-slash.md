Les commandes slash sont des instructions spéciales que tu tapes au début d'un message (`/help`, `/clear`...) pour contrôler Claude Code lui-même, plutôt que de lui demander de coder quelque chose.

## Quand l'utiliser

Utilise une commande slash chaque fois que tu veux agir sur la session elle-même : changer de modèle, vider le contexte, gérer les permissions, lancer une revue de code... Une commande slash n'est reconnue que si elle est le tout premier mot de ton message.

## Exemple minimal

```text [Dans la session Claude Code]
/help
```

Affiche la liste des commandes disponibles et un résumé de l'aide, directement dans le terminal.

## Exemple réaliste

Voici les commandes les plus utiles au quotidien, regroupées par usage.

::steps{level="3"}
### Découvrir et gérer la session

| Commande | Effet |
| --- | --- |
| `/help` | Affiche l'aide et les commandes disponibles |
| `/clear [nom]` | Démarre une conversation avec un contexte vide |
| `/compact [instructions]` | Résume la conversation pour libérer du contexte |
| `/context [all]` | Visualise l'usage actuel du contexte |
| `/cost` | Alias de `/usage` : coût et consommation de la session |
| `/exit` | Quitte la CLI |

### Permissions et modèle

| Commande | Effet |
| --- | --- |
| `/permissions` | Gère les règles allow / ask / deny |
| `/model [modèle]` | Change le modèle utilisé |
| `/config [clé=valeur]` | Ouvre les réglages, ou en modifie un directement |

### Sessions et navigation

| Commande | Effet |
| --- | --- |
| `/resume` | Reprend une conversation précédente |
| `/rename [nom]` | Renomme la session en cours |
| `/branch [nom]` | Crée une branche de la conversation pour tester une autre direction |
| `/cd <chemin>` | Déplace la session vers un autre dossier de travail |

### Travail sur le code

| Commande | Effet |
| --- | --- |
| `/diff` | Revoit les changements dans ton dossier de travail |
| `/code-review [pr#\|branche\|chemin]` | Revoit un diff, une PR, une branche ou un chemin |
| `/init` | Initialise le projet avec un fichier `CLAUDE.md` |
| `/agents` | Gère les configurations de subagents |

### Mémoire et configuration

| Commande | Effet |
| --- | --- |
| `/memory` | Édite les fichiers `CLAUDE.md` et la mémoire automatique |
| `/hooks` | Affiche la configuration des hooks |
| `/mcp [reconnect\|enable\|disable]` | Gère les connexions aux serveurs MCP |

### Aide et diagnostic

| Commande | Effet |
| --- | --- |
| `/doctor` | Lance un diagnostic complet et corrige les problèmes courants |
| `/bug [rapport]` | Signale un bug ou partage ta conversation |
| `/feedback [rapport]` | Envoie un retour produit |
::

## Pièges fréquents

::warning
**Une commande slash doit être le premier mot du message.** `explique-moi /help` n'est pas reconnu comme une commande — Claude la lit comme du texte normal.
::

::note
**`/clear` et `/compact` ne font pas la même chose.** `/clear` repart avec un contexte totalement vide (la conversation précédente reste accessible via `/resume`). `/compact` résume la conversation en cours pour libérer de la place, sans l'interrompre — voir la page dédiée à la gestion du contexte pour le détail.
::

::caution
**La liste des commandes évolue à chaque version.** Certaines commandes citées ici peuvent être renommées ou remplacées ; lance `/help` dans ta session pour voir la liste exacte disponible sur ta version.
::
