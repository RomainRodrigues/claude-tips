Claude Code répond à une série de raccourcis clavier pour changer de mode, gérer ta saisie, annuler une action ou naviguer dans l'historique — sans jamais toucher à la souris.

## Quand l'utiliser

Ces raccourcis fonctionnent à tout moment dans une session interactive. Les connaître évite de taper des commandes slash pour des actions très fréquentes (changer de mode, interrompre Claude, effacer l'écran).

## Exemple minimal

Les trois raccourcis que tu utiliseras le plus souvent :

| Raccourci | Effet |
| --- | --- |
| :kbd{value="Shift+Tab"} | Change de mode de permission |
| :kbd{value="Escape"} | Interrompt Claude en cours d'action |
| :kbd{value="Ctrl+C"} | Annule la saisie en cours / interrompt |

## Exemple réaliste

Voici les raccourcis par cas d'usage, regroupés comme tu les rencontreras en pratique.

::steps{level="3"}
### Contrôler la session

| Raccourci | Effet |
| --- | --- |
| :kbd{value="Ctrl+C"} | Annule l'opération en cours |
| :kbd{value="Ctrl+D"} | Quitte Claude Code (appuie deux fois en moins de 800ms pour confirmer) |
| :kbd{value="Escape"} | Annule la saisie en cours dans le champ de texte |
| :kbd{value="Escape"} :kbd{value="Escape"} | Ouvre le menu de rewind (annuler du code/de la conversation) — voir la page dédiée aux checkpoints |

### Écrire ton message

| Raccourci | Effet |
| --- | --- |
| :kbd{value="Enter"} | Envoie le message |
| :kbd{value="Ctrl+J"} | Insère un retour à la ligne sans envoyer |
| :kbd{value="Ctrl+G"} | Ouvre le message dans ton éditeur externe |
| :kbd{value="Ctrl+V"} (ou :kbd{value="Alt+V"} sur Windows/WSL) | Colle une image depuis le presse-papier |

### Naviguer dans l'historique

| Raccourci | Effet |
| --- | --- |
| :kbd{value="↑"} / :kbd{value="↓"} | Message précédent / suivant dans ton historique |
| :kbd{value="Ctrl+R"} | Ouvre la recherche dans l'historique |

### Modes et affichage

| Raccourci | Effet |
| --- | --- |
| :kbd{value="Shift+Tab"} | Fait défiler les modes de permission |
| :kbd{value="Ctrl+T"} | Affiche/masque la liste des tâches en cours de Claude |
| :kbd{value="Ctrl+O"} | Affiche/masque la transcription détaillée |
| :kbd{value="Ctrl+L"} | Réaffiche l'écran (garde ta saisie et la conversation) |
::

## Pièges fréquents

::note
**Ces raccourcis sont personnalisables.** Lance `/keybindings` pour ouvrir ton fichier de configuration (`~/.claude/keybindings.json`) et changer, ajouter ou désactiver un raccourci.
::

::warning
**Certains raccourcis sont réservés et ne peuvent pas être réassignés** : `Ctrl+C` (interruption), `Ctrl+D` (quitter), et quelques autres liés au fonctionnement bas niveau du terminal.
::

::caution
**`Ctrl+B`, `Ctrl+A` et `Ctrl+Z` peuvent entrer en conflit avec ton terminal.** `Ctrl+B` est le préfixe par défaut de tmux, `Ctrl+A` celui de GNU screen, et `Ctrl+Z` suspend un processus sous Unix. Si tu utilises un multiplexeur de terminal, ces raccourcis peuvent ne pas atteindre Claude Code directement.
::
