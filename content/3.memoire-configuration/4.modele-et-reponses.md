Trois réglages indépendants changent la façon dont Claude répond : le **modèle** (Opus, Sonnet, Haiku...), le **fast mode** (vitesse contre coût), et l'**output style** (le ton et le format des réponses).

## Quand l'utiliser

Change de modèle selon la difficulté de la tâche : un modèle plus léger pour une tâche simple et rapide, un modèle plus capable pour une tâche complexe ou longue. Active le fast mode quand tu veux des réponses plus rapides et que tu es prêt à payer plus cher en cas d'usage supplémentaire. Change d'output style quand tu veux que Claude adopte un ton différent en permanence, plutôt que de le répéter à chaque message.

## Exemple minimal

::code-group
```text [Changer de modèle]
/model sonnet
```

```text [Activer le fast mode]
/fast
```

```text [Changer d'output style]
/output-style Explanatory
```
::

Chacune de ces commandes s'utilise sans argument pour ouvrir un menu de sélection interactif.

## Exemple réaliste

Un `settings.json` personnel qui fixe un modèle de départ, un niveau d'effort, et un output style, pour ne plus avoir à les redéfinir à chaque session :

```json [~/.claude/settings.json]
{
  "model": "opus",
  "effortLevel": "high",
  "outputStyle": "Explanatory"
}
```

Pour un besoin ponctuel — une seule session sur Opus sans changer ton réglage par défaut :

```bash [Terminal]
claude --model opus
```

Et pour aller au maximum de la vitesse sur une tâche interactive, en combinant fast mode et un modèle qui le supporte :

```text [Dans une session Claude Code]
/model opus
/fast
```

## Comprendre chaque réglage

::accordion
  :::div{label="Le modèle"}
  Claude Code résout le modèle dans cet ordre de priorité : `/model` en session > `--model` au lancement > variable d'environnement `ANTHROPIC_MODEL` > clé `model` dans les settings > `ANTHROPIC_DEFAULT_MODEL`. Les alias disponibles : `opus` (raisonnement complexe), `sonnet` (usage quotidien), `haiku` (rapide et simple), `fable` (tâches longues et ambiguës), et `opusplan` (Opus en mode plan, puis Sonnet pour l'exécution).
  :::

  :::div{label="Le fast mode"}
  Le fast mode rend Opus jusqu'à 2,5x plus rapide, au prix d'un coût par token plus élevé — ce n'est pas un modèle différent, seulement une configuration API différente. Disponible uniquement sur Opus 5 et Opus 4.8, pas sur Sonnet ni Haiku. Se toggle avec `/fast`, ou en réglant `"fastMode": true` dans tes settings utilisateur.
  :::

  :::div{label="Les output styles"}
  Les output styles changent les instructions par défaut envoyées à Claude — son rôle, son ton, son format — pour **chaque** réponse, contrairement à CLAUDE.md qui ajoute du contexte projet. Quatre styles intégrés en plus du style par défaut : **Proactive** (agit sans attendre de décisions de routine), **Concise** (va droit au résultat), **Explanatory** (ajoute des « Insights » pédagogiques), et **Learning** (te fait coder des petits bouts toi-même avec des marqueurs `TODO(human)`).
  :::
::

## Pièges fréquents

::warning
**Le fast mode ne s'active que sur un modèle qui le supporte.** Si ton modèle actuel ne le supporte pas (Sonnet, Haiku), activer `/fast` bascule automatiquement sur Opus. Désactiver le fast mode ensuite ne te ramène pas à ton ancien modèle — utilise `/model` pour ça.
::

::caution
**Le coût du fast mode se paie une fois par conversation, dès la première activation.** La première fois que tu actives le fast mode dans une conversation, tu paies le prix plein du fast mode pour tout le contexte déjà accumulé. Plus tu es loin dans la conversation, plus ça coûte cher : active-le en début de session plutôt qu'en cours de route si tu veux limiter le coût.
::

::note
**`s` dans le sélecteur `/model` ou `/effort` ne sauvegarde rien.** Appuyer sur `Entrée` change le modèle ou le niveau d'effort *et* l'enregistre comme réglage par défaut pour tes prochaines sessions. Appuyer sur `s` ne change que la session en cours, sans toucher à ton réglage sauvegardé.
::

::note
**Un output style personnalisé n'inclut pas les instructions d'ingénierie logicielle de Claude Code par défaut.** Si tu changes seulement le ton mais que Claude doit continuer à coder comme d'habitude, ajoute `keep-coding-instructions: true` dans le frontmatter de ton style personnalisé.
::
