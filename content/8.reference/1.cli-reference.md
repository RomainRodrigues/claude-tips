Cette page rassemble les commandes et flags les plus utiles de la commande `claude`, sous forme de tableau, pour un usage courant. Ce n'est **pas** une liste exhaustive : `claude --help` n'affiche même pas tous les flags qui existent, alors cette page en affiche encore moins. Pour tout le détail, va voir la doc officielle en bas de page.

## Commandes

Tape ces commandes directement dans ton terminal (pas dans une session Claude Code déjà ouverte).

| Commande | Effet | Exemple |
| --- | --- | --- |
| `claude` | Démarre une session interactive | `claude` |
| `claude "question"` | Démarre une session interactive avec un premier message déjà envoyé | `claude "explique ce projet"` |
| `claude -p "question"` | Pose une question et quitte (mode non-interactif) | `claude -p "explique cette fonction"` |
| `cat fichier \| claude -p "question"` | Traite un contenu envoyé par un tube (pipe) | `cat logs.txt \| claude -p "explique"` |
| `claude -c` | Reprend la conversation la plus récente du dossier courant | `claude -c` |
| `claude -r "<session>" "question"` | Reprend une session précise par son ID ou son nom | `claude -r "auth-refactor" "termine cette PR"` |
| `claude update` | Met à jour Claude Code vers la dernière version | `claude update` |
| `claude doctor` | Diagnostic en lecture seule de l'installation et des settings, sans démarrer de session | `claude doctor` |
| `claude mcp` | Configure les serveurs MCP | `claude mcp add ...` |
| `claude auth login` / `logout` / `status` | Connexion, déconnexion, statut d'authentification | `claude auth status` |

## Flags les plus utiles

### Session et mode de permission

| Flag | Effet | Exemple |
| --- | --- | --- |
| `-p`, `--print` | Affiche la réponse sans mode interactif (mode non-interactif / scripts) | `claude -p "query"` |
| `-c`, `--continue` | Charge la conversation la plus récente du dossier courant | `claude --continue` |
| `-r`, `--resume` | Reprend une session précise par ID ou nom, ou ouvre un sélecteur | `claude --resume auth-refactor` |
| `--fork-session` | En reprenant une session, crée un nouvel ID au lieu de réutiliser l'original | `claude --resume abc123 --fork-session` |
| `--permission-mode` | Démarre dans un mode de permission donné (`default`, `acceptEdits`, `plan`, `auto`, `dontAsk`, `bypassPermissions`) | `claude --permission-mode plan` |
| `--dangerously-skip-permissions` | Saute toutes les invites de permission (équivalent à `--permission-mode bypassPermissions`) | `claude --dangerously-skip-permissions` |
| `--model` | Choisit le modèle pour la session (alias comme `sonnet`, `opus`, `haiku`, ou nom complet) | `claude --model sonnet` |
| `--add-dir` | Ajoute des dossiers de travail supplémentaires que Claude peut lire/modifier | `claude --add-dir ../apps ../lib` |
| `-n`, `--name` | Donne un nom à la session, réutilisable avec `--resume` | `claude -n "mon-projet"` |
| `--session-id` | Fixe un ID de session précis (doit être un UUID valide) | `claude --session-id 550e8400-...` |

### Automatisation et scripts (mode `-p`)

| Flag | Effet | Exemple |
| --- | --- | --- |
| `--output-format` | Format de sortie du mode `-p` : `text`, `json`, ou `stream-json` | `claude -p "query" --output-format json` |
| `--input-format` | Format d'entrée du mode `-p` : `text` ou `stream-json` | `claude -p --input-format stream-json` |
| `--max-turns` | Limite le nombre de tours agentiques (mode `-p` uniquement) | `claude -p --max-turns 3 "query"` |
| `--max-budget-usd` | Plafond de dépense en dollars avant arrêt (mode `-p` uniquement) | `claude -p --max-budget-usd 5.00 "query"` |
| `--allowedTools`, `--allowed-tools` | Outils exécutés sans demander de permission | `claude --allowedTools "Bash(git log *)" Read` |
| `--disallowedTools`, `--disallowed-tools` | Règles de refus pour des outils précis | `claude --disallowedTools Edit` |
| `--tools` | Restreint les outils disponibles à cette liste | `claude --tools "Read,Edit,Bash"` |
| `--permission-prompts` | Qui répond aux invites de permission en mode `-p` (`host` ou `none`) | `claude -p --permission-prompts none "query"` |
| `--append-system-prompt` | Ajoute du texte à la fin du system prompt par défaut | `claude --append-system-prompt "Utilise toujours TypeScript"` |

### Diagnostic et personnalisation

| Flag | Effet | Exemple |
| --- | --- | --- |
| `-v`, `--verbose` | Affiche plus de détails de diagnostic (cumulable jusqu'à `-vvvvv`) | `claude -p --verbose "query"` |
| `--debug` | Active le mode debug, avec filtrage optionnel par catégorie | `claude --debug='mcp,startup'` |
| `--safe-mode` | Démarre avec toutes les personnalisations désactivées (CLAUDE.md, skills, hooks, MCP, plugins...) pour isoler un problème de config | `claude --safe-mode` |
| `--bare` | Mode minimal : saute la découverte des hooks, skills, commandes, subagents, plugins, MCP, mémoire auto et CLAUDE.md pour démarrer plus vite | `claude --bare -p "query"` |
| `--settings` | Charge des settings depuis un fichier JSON ou une chaîne JSON | `claude --settings '{"model":"sonnet"}'` |
| `--mcp-config` | Charge des serveurs MCP depuis des fichiers JSON | `claude --mcp-config ./mcp.json` |
| `--fallback-model` | Bascule automatiquement sur un ou plusieurs modèles de secours si le modèle principal est surchargé | `claude --fallback-model sonnet,haiku` |
| `--version` | Affiche la version de la CLI Claude Code | `claude --version` |

::note
**`claude --help` ne liste pas tout.** L'absence d'un flag dans `--help` ne veut pas dire qu'il n'existe pas — la doc officielle en liste beaucoup plus que ce qui est affiché en ligne de commande.
::
